# NAMMA BUS - Intelligent Transportation System

## Overview

NAMMA BUS is an IoT-based Intelligent Transportation System developed for real-time bus tracking, route monitoring, and ETA prediction.

## Technologies Used

- React.js
- Node.js
- Firebase
- ESP32
- GPS Module
- Google Maps API
- Deep Learning

## Features

- Real-time Bus Tracking
- ETA Prediction
- Admin Dashboard
- Driver Mobile Application
- Student Bus Search System

## Hardware Components

- ESP32 Development Board
- GPS Module
- GPS Antenna
